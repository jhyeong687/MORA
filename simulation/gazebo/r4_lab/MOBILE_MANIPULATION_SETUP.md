# R4 이동·집기·운반 기본 환경

최신 작업일: 2026-11-12. 현재 목적은 **연구 모델 적용 전 기본 환경의 기능 확인**이다. MolmoAct2와 HomeBody 설치·학습·모델 성능 비교는 이번 범위에 포함하지 않는다.

**사용자의 재개 요청으로 기본 동작 실험을 이어가는 중이다.** 과거 중지 시점의 기록은 `session_stop/`에 보존했다. 전체 집기·운반·놓기 미션은 아직 미완료이며, 현재는 파지 반복성을 먼저 점검한다.

## 실행

새 월드를 한 터미널에서 시작한다:

```bash
~/r4_lab/start_pick_place
```

센서 수신이 시작되면 다른 터미널에서 순차 기본 시험을 실행한다:

```bash
~/r4_lab/test_pick_place
```

기존 실행 중인 다른 SLAM 월드와 중복 실행하지 않는다. 한 시험의 시작 위치와 물체 상태를 다음 시험의 초기 상태로 혼동하지 않는다. 재시험은 월드를 새로 시작한다.

## 구성과 관측

- TurtleBot3 + SO-ARM101 결합 모델, 바퀴 토크 제어와 팔 6개 관절 토크 기반 위치 제어.
- SLAM은 LiDAR와 엔코더 odom을 사용한다. 이동 피드백은 `map -> base_footprint` TF다.
- 작업대 2개, 동적 빨간 큐브 1개(32 mm, 10 g). 장면과 waypoint는 `slam/pick_place.yaml`에 지정한다.
- **RGB-D를 쓰지 않는다.** 기존 손목 RGB 영상 `/wrist_cam/image`와 `/wrist_cam/camera_info`를 사용한다.
- 물체의 명목 위치·크기·작업대 높이는 장면 사양으로 제공한다. RGB 큐브 bounding box와 카메라 기하로 마지막 접근을 보정하는 단순 기준 방식이다. 임의 물체 인식이나 VLA에 의한 인식으로 해석하지 않는다.
- 낮은 2D LiDAR가 작업대 상판을 놓칠 수 있어 작업대 footprint를 명시적 keep-out prior로 사용한다. 관측하지 않은 상판을 SLAM이 알아냈다고 주장하지 않는다.
- 경로는 실제 `/map` 점유 격자에 A*와 장애물 팽창을 적용하여 계획한다. 장애물·피드백 유실·기울기 감시를 유지한다.
- 손가락 2개의 접촉 센서를 기록한다. 물체는 손가락-물체의 **물리 접촉과 마찰**로 집도록 시험한다. 물체 teleport나 자동 부착으로 집기를 대체하지 않는다.
- 원본의 단일 convex collision hull은 실제 손가락 사이의 빈 공간까지 메우는 현상이 확인됐다. pick/place 장면에 한해 hand body와 사각 finger pad로 충돌 형상을 분리했다. 원본 visual mesh·질량·모터 토크 상한은 유지한다. 이는 기본 동작용 접촉 근사이며 실물 손가락/고무 재질을 식별한 모델은 아니다.
- `/evaluation/object_odom`은 물체가 실제 들렸는지·운반됐는지·작업대에 놓였는지 평가하는 데만 사용한다. 이 토픽으로 집기 위치나 주행 목표를 생성하지 않는다.

## 순차 시험

1. 짧은 SLAM 지도 작성 주행.
2. pickup waypoint로 이동하고 방향 정렬.
3. RGB 영상과 알려진 큐브 사양으로 상대 위치 확인.
4. 팔 사전 접근 → 손가락 사이로 접근 → 그리퍼 닫기 → 들어 올리기.
5. 물체 실제 상승을 평가하고 운반 자세로 전환.
6. delivery waypoint로 이동.
7. 내려놓기 → 그리퍼 열기 → 팔 후퇴 → 물체 안정 위치 평가.

현재 전체 시나리오의 실행 결과는 시험 폴더의 `metrics.json`, `events.json`, `error.txt`가 기준이다. 완료하지 않은 시험을 성공으로 표시하지 않는다.

첫 `pick_place_attempt1`은 지도 작성·pickup 이동·RGB 확인까지 완료했지만 물체를 밀고 lift에 실패했다. 이 결과를 계기로 충돌 형상을 분리하고, 팔 조작 중 베이스 위치 유지와 관절 피드백을 이용한 중력 처짐 보정을 추가했다. 모터 상한을 임의로 높이거나 물체를 부착하지 않았다.

`pick_place_attempt2`에서는 두 손가락과 큐브의 실제 contact 기록, 큐브 상승을 확인했다. 이후 별도 접힘 운반 자세로 바꾸다가 팔 추종 실패와 낙하가 발생했다. 이 열린 장면에서는 불필요한 접힘 자세 변경을 제거하고, 이미 물체를 들고 유지한 자세로 운반하도록 단순화했다. 전체 이송 성공과 구분하여 보존한다.

`pick_place_attempt3`는 수정 후 새 초기 상태에서 재시험했으나 물체가 전방으로 밀려 lift에 실패했다. 반복 가능한 파지는 아직 해결되지 않았다. 사용자가 여기서 실험을 종료했다. 따라서 운반·놓기 성공은 주장하지 않는다. 마지막 지도, SLAM pose graph, 소스/설정/플러그인 사본은 `slam/results/research_20261112/session_stop/`에 저장했다.

## 이미 확인한 팔 기본 동작

`slam/results/research_20261112/arm_joint_smoke_retry/metrics.json`:

- shoulder pan/lift, elbow flex, wrist flex/roll, gripper 6개를 각각 2개 목표로 이동하고 복귀했다.
- 12개 유지 구간이 모두 작은 범위 판정(<3°)을 통과했다. 최대 유지 평균 절대 오차는 elbow 약 0.80°였다.
- 20 Hz 목표 명령, 1,182개 기록 샘플. 최대 베이스 변위 약 1.96 mm.
- 전 범위·자기충돌·파지·실물 보정을 검증한 것은 아니다.
- 첫 `arm_joint_smoke` 시도는 기존 GUI/시뮬레이터 종료 뒤 센서가 없어 준비 단계에서 멈췄다. 모터 동작 실패로 분류하지 않는다. `arm_joint_smoke_retry`가 실제 동작 시험이다.

## 자료 저장

- 개별 시험의 `console.log`, `events.json`, 관절 목표/실제값, 접촉 기록, 물체 평가 궤적, 지도/로봇 궤적, 설정·소스 사본을 보존한다.
- 사진과 영상은 기능 확인에 필요한 핵심 장면을 별도 선별한다. 중복·대기 장면을 모두 배포하지 않는다.
- 영상의 시간은 wall time이고 시뮬레이션 시간은 각 기록의 `/clock`/`sim_time`이다.
- 장면·단계별 동작은 단순 기준 제어기이며 학습 정책의 성능 자료가 아니다.

## 나중 연구를 위한 짧은 참고 메모

지금 구현한 입력은 RGB·관절 상태·SLAM 위치·작업 지시, 출력은 베이스 속도·팔 절대 관절 목표·그리퍼 명령이다. 이동과 팔 동작을 함수로 구분하므로 이후 모델 어댑터를 별도로 붙일 수 있다.

- **MolmoAct2**: SO100/101용 checkpoint와 절대 관절 제어 규약이 공개되어 있다. 원본 checkpoint와 LeRobot 변환본은 관절 보정 convention이 다를 수 있다. 현재 시뮬레이터 rad/zero 값을 모델에 그대로 넣지 않는다. 모델 접속 전 카메라 키, 단위, zero/sign, gripper 정규화, action chunk를 확인할 것. [공식 SO100/101 모델 카드](https://huggingface.co/allenai/MolmoAct2-SO100_101), [LeRobot 공식 설명](https://github.com/huggingface/lerobot/blob/main/docs/source/molmoact2.mdx).
- **HomeBody (2026-09)**: 공간 기억과 재사용 가능한 이동·조작 스킬을 상위 VLM이 조합하는 시스템을 참고할 수 있다. 동일한 팔 VLA 모델로 취급하지 않으며 G1/Isaac Sim 구현을 이 Gazebo 로봇에 재현했다고 주장하지 않는다. 현재는 단계별 실행 결과·관측을 저장하는 구조만 준비한다. [Stanford 공식 프로젝트](https://tml.stanford.edu/homebody/).
- **MolmoB0T (2026, v3 11-08)**: 시뮬레이션 조작 데이터와 모바일 조작 평가 구성의 참고 자료다. 이 기본 세팅 한 장면의 성공을 해당 논문의 sim-to-real 결과와 동등하게 해석하지 않는다. [논문](https://arxiv.org/abs/2603.16861).

공식 자료 확인일: 2026-11-12. 모델 파일 다운로드·GPU 추론·학습은 아직 하지 않았다.
